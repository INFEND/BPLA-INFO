# Импорт БПЛА ВСУ ПДФ.pdf (60 страниц)

Источник: PDF, загруженный пользователем. SHA-256 исходного файла:
`2913a58a55163c912160539b44509a772fa518d4fbd7ff9b4cd03dbeaf044b65`.

Импортирован **отдельный дополнительный источник** `app/src/main/assets/catalog_bpla_vsu_pdf.json`, 34 отдельные страницы с карточками моделей, 167 пар общих характеристик. Модель идентифицируется по явному `targetId` (23 записи), где соответствие задано вручную; остальные 11 записей появляются отдельно, без слияния по неуверенному сходству названия.

Существующие 87 базовых и 374 дополнительных записи не изменялись. При повторном запуске приложение не создаёт дубликаты благодаря ключу `vsu_pdf_revision`. Изменения в пользовательских именах, избранном, фото и оригинальных характеристиках не затрагиваются. Для дополняемых карточек каждая строка помечается страницей из этого PDF.

**Не подтверждено:** независимая достоверность характеристик; в оригинальном документе встречаются расхождения, например «Стрепет С» на странице 55 (крейсерская скорость указана выше максимальной). Фотографии из PDF не импортировались, поскольку лицензии на их изменение и распространение не подтверждены. Военные радиочастоты, схемы противодействия и инструкции из документа не переносились.

Особо: на странице 52 указан пакистанский `Vector (Integrated Dynamics)`, на странице 58 немецкий `Quantom Vector (Quantum Systems)`. Эти записи не смешиваются.
