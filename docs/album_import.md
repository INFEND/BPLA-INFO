# Авиационный каталог из пользовательского PDF

Исходный документ содержал 146 именных карточек, в том числе **15 морских и 11 наземных**. Из него в APK с версии 1.0.20 попадают только **120 авиационных** записей (103 самолётные, 11 коптерных, 6 барражирующих).

Оригинальный бинарный файл перенесён из `app/src/main/assets/` в `research/source_catalogs/catalog_album_2026_original.dat`. Он остаётся доступным для воспроизводимости исследования, **но не входит в приложение**. Перед каждой сборкой `scripts/filter_air_catalog.py` генерирует сжатую авиационную часть в `app/build/generated/air-catalog-assets/catalog_album_2026.dat`. GitHub Actions проверяет **физическое содержимое** debug, release и подписанного APK, включая отсутствие неавиационных записей.

В установленных ранее версиях морские и наземные записи могли сохраниться в SharedPreferences. При первом запуске 1.0.20 они удаляются из активного каталога **только после успешного синхронного сохранения** исходного JSON в `archived_non_air_v1` приложения. Изображения пользователей и избранное сохраняются внутри резервной записи, а сами файлы фотографий не удаляются. Экспорт/импорт каталога работает только с авиационными моделями.

Характеристики из альбома не подвергались независимой верификации, а изображения PDF не импортировались из-за неизвестных прав на обработку.
