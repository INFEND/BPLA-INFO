# Импорт альбома беспилотных систем

Исходный файл: «Альбом беспилотных авиационных, морских и наземных систем, используемых…». SHA-256 PDF: `fb7b03cf3a0693fc2233c82ab3de0eaf1b3e9cb9b61585c7a9fb62ab2eaa94fe`.

Исходный PDF фактически содержит **156 страниц**, из которых последняя пустая; пользовательский просмотр показывает 155 содержательных страниц. Из текста страниц извлечено **146 именных карточек** и **714 пар общих технических показателей**: 103 самолётного типа, 11 коптерных, 6 барражирующих, 15 морских и 11 наземных. Страница с обобщёнными FPV не считается отдельной моделью.

Данные сохранены внутри APK в `app/src/main/assets/catalog_album_2026.dat` (GZip JSON, 4776 байт), проверяются CI после компиляции и подписи. Для каждой карточки указан **номер страницы PDF**. Количественные характеристики приводятся как данные **из документа**, без самостоятельной проверки, могут содержать противоречия.

Импорт в `DroneStore.mergeAlbum` происходит один раз по ревизии; существующие записи дополняются **атрибутированными полями**, исходные значения, пользовательские фото и избранное не меняются. Предусмотрены только строгие совпадения имён с категорией и вручную заданные эквиваленты; модификации с неоднозначными названиями не объединяются. Например, обозначение «РD-2 Лютый» на странице 35 сохранено как отдельное, поскольку документ смешивает названия.

**Не импортированы:** изображения неизвестных прав, боевые нагрузки, частоты/связь, способы применения и противодействия, любые инструкции; фото не генерировались.

Секция «Морской» и «Наземный» добавлена к фильтрам Android. Без фотографий приложение по-прежнему показывает стандартный плейсхолдер и поддерживает локальные пользовательские изображения.
