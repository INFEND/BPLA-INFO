# БПЛА ИНФО: дополнение из бюллетеня №30 (2025)

Источник: пользовательский PDF на 213 страницах, «Справочник по беспилотным летательным аппаратам, применяемым вооружёнными силами Украины», информационно-технический бюллетень №30 (2025). SHA-256 документа сохранён в `app/src/main/assets/bulletin30_2025.json`.

Извлечено 381 описание на страницах 7–61, 64–191, 194–201, 204. После объединения семи повторных названий внутри категории сохранены **374 карточки и 3516 строк характеристик**: 109 самолётных, 248 коптерных, 15 барражирующих, 2 аэростата. Данные в карточках связаны с номером страницы, типом и статусом неоднозначной модификации.

Исходные 87 моделей из другого каталога не удаляются. Только совпадающие нормализованные названия с совместимым типом объединяются; существующие характеристики, фотографии, избранное и локальные пользовательские данные не заменяются. Добавляемые к прежней карточке характеристики имеют отдельную подпись «БЮЛЛЕТЕНЬ №30».

Этот источник военно-ведомственный и **не прошёл независимую проверку**. В таблицах возможны опечатки, несовпадения единиц измерения и разные модификации под одинаковым названием. Неправдоподобные значения не исправлялись предположениями. Пять явно ошибочных сочетаний граф и значений удалены при консервативном переносе.

Военные инструкции, схемы боевого применения, процедуры наведения, а также фотографии из PDF не переносились. Авторские права на фотографии в PDF не установлены. Сетевые фотоссылки не добавлялись. OTA и локальная пользовательская галерея не изменены.

Проверка: `python3 -m unittest discover -s tests -v`. Сборка Android и проверка её декодирования и подписи выполняются отдельно в GitHub Actions.
