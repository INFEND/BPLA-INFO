## Очередь по приоритету
1. Устранить сетевые блокировки Wikimedia при проверке (403/429/503/тайм-ауты). Строгая проверка пока не пройдена: GitHub-hosted runner получает Retry-After 600 секунд. Actions 41509871598 завершился INCONCLUSIVE: HEAD 200 image/* у 5 из 60, ещё 55 HTTP 429/недоступно, 0 доказанных отсутствующих. Проверяющий скрипт теперь останавливается при Retry-After >30 секунд, чтобы не продолжать десятки запросов во время явного запрета; следующим шагом подтвердить GET изображения, MIME, разрешение и декодирование. Не считать HTTP HEAD подтверждением Android-галереи. **Не** принимать блокировку за успех.
2. Протестировать реальную загрузку на Android: 5 фото в карточке, полноэкранный просмотр, повторный вход, офлайн-кэш, битый файл кэша, отсутствие сети.
3. Для 60 записей собрать и сверить страницу Commons, автора, лицензию, реальное содержимое и разные ракурсы. Недостоверные или несуществующие записи исправлять только после проверки.
4. Закрыть 7 частичных галерей и 71 модель без фотографий, используя 3–5 лицензированных реальных снимков, если доступны. Сохранять отметку «неполное покрытие», когда подходящих снимков меньше.
5. Добавить отдельный подписанный/хешированный версионируемый каталог изображений с проверкой SHA-256 и ограниченным Android-кэшем. Не использовать приватные API или секреты в APK.
6. После подтверждённой сборки и проверки изображений выпускать отдельный APK-релиз с новым versionCode/versionName; до этого не публиковать непроверенный хотфикс.

## Правило отчётности
`Photo sources integrity` должен завершаться ошибкой, если хоть одна ссылка недоступна для проверки. Это состояние **INCONCLUSIVE**, а не доказательство отсутствия файла. Отдельно учитывать `MISSING` (подтверждённая ошибка URL).
