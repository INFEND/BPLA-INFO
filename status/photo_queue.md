# Очередь фотографий БПЛА ИНФО

Обязательное правило с 03.11.2026: пользователь запретил Wikimedia/Wikipedia и загрузку фотографий моделей по интернет-ссылкам. Фото должны быть **реальными файлами внутри APK** (при явном выборе пользователем допустим Google Drive как место хранения). Ни один внешний фото URL не должен использоваться галереей Android.

## Выполненный переход
- Старые 60 Wikimedia-записей удалены из активного манифеста; новый `app/src/main/assets/bundled_photos.json` со схемой 2 и `storage=apk-assets-only`.
- `PhotoLibrary` получает только встроенные файлы `assets/photos/*`, проверяет SHA-256, размер и декодирование без HTTP.
- Удалены работающие процессы внешних фотографий, старые проверки Commons и скрипты их поиска.
- Устаревшие файлы в кэше `uav-photos` удаляются при запуске новой версии. Пользовательские content:// фото сохранены.
- Не добавлять ни одной записи без фактического проверенного файла изображения и разрешённых прав на распространение/обработку.

## Следующие приоритеты
1. Найти реальные фотографии БПЛА из **не-Wikimedia** источников с правами на редактирование и распространение, для каждой модели до 3–5 разных ракурсов; запретить дубликаты и генерации.
2. Подготовить чистые оригиналы и оптимизированные WebP/PNG, удалить отвлекающий фон только с разрешением и без изменения реальных деталей.
3. Физически добавить каждый бинарный файл в `app/src/main/assets/photos/`, заполнить манифест автор/лицензия/источник/SHA-256, проверить тестами.
4. Проверить Android CI и галерею на устройстве, затем выпускать следующие подписанные APK OTA. Никогда не добавлять интернет-загрузку фотокартинок.
5. Сохранить пользовательские фото, каталог, импорт и экспорт и работу OTA.

Статус: новый манифест начинается с нуля, пока реальных вложенных лицензированных изображений нет. Количество подтвердить проверкой GitHub перед каждым отчётом.
