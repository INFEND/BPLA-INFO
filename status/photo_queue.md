# БПЛА ИНФО · очередь локальных фотографий

Дата изменения: 03.11.2026.

## Решение владельца
Никаких Wikimedia/Wikipedia и интернет-ссылок на фотографии в Android. Реальные изображения должны быть вложены в APK, либо сохраняться на Google Диск при явно согласованной папке. Выбран APK; не менять это решение в автозадаче.

## Подтверждено
- Каталог: 87 моделей.
- Старая база из 60 Wikimedia-ссылок удалена из рабочего дерева (вместе с сетевым загрузчиком, scripts и workflows).
- Новый формат `bundled_photos.json`: только реально существующие файлы в `assets/photos/`, автор/лицензия/источник и SHA-256.
- В GitHub уже записаны и проверены 2 автономных WebP: модель **PUMA AE RQ-20**, Дэниел Амбург (DVIDS 8347955) и Лэнс-корпорал Хосе Гонсалес (DVIDS 6381574), Public Domain (US Gov). Это 1 из 87 моделей с новыми встроенными фото; пока 2 ракурса, а не требуемые 3–5.
- Старый кэш `uav-photos` должен быть удалён при первом запуске обновлённого APK. Пользовательские файлы через системный выбор не удаляются.
- Загрузка/кэш фотографий из внешней сети отключены; интернет разрешён только для OTA APK.

## Дальнейшая работа
1. Проверить реальный просмотр двух встроенных снимков на Android, полноэкранный режим и автономность без сети.
2. Находить реальные изображения моделей с явными правами на обработку/распространение из источников, **не являющихся Wikimedia**, включать только бинарные файлы в APK.
3. Для каждой модели 3–5 уникальных ракурсов по возможности; нет лицензированных фото => честный пустой блок «Фото пока не добавлены».
4. Осторожно удалять фон и посторонние объекты без создания несуществующих деталей, проверять итог глазами и автоматически.
5. Результаты проверять тестами SHA-256, лицензии, целостности; выпускать новые подписанные версии OTA после CI success.

**Не восстанавливать прежние Wikimedia URLs ни при каких обстоятельствах.**
