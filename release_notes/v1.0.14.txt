БПЛА ИНФО 1.0.14

Добавлено:
• Дополнительный каталог из справочника 2025 года: 374 карточки и 3516 строк характеристик.
• В каждой карточке дополнительного каталога указан источник и страница PDF.
• Совпадающие модели объединяются без перезаписи прежних характеристик, избранного и локальных пользовательских фотографий.
• При неоднозначности модификации выводится соответствующее предупреждение.
• Фото-прогресс учитывает новые модели, сохраняя требование минимум трёх подтверждённых обработанных ракурсов на модель.

Важно:
• Характеристики бюллетеня переданы с указанием источника, но не проверены независимо.
• Новые фотографии из PDF не добавлены из-за отсутствия подтверждённых прав.
• Фотографии хранятся только в APK либо добавляются пользователем локально. Сетевые фотозагрузчики не используются.
• Существующие две фотографии RQ-20 Puma по-прежнему требуют дообработки фона.

Проверки:
• Автоматические тесты и сравнение фактических байтов обоих каталогов внутри APK, включая подписанный релиз.
• OTA только через GitHub Releases, прежний сертификат подписи.
