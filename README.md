# БПЛА ИНФО

Нативный русскоязычный каталог беспилотных летательных аппаратов для Android.

## Возможности

- Полноэкранные карточки со сведениями о конструкции, габаритах, полёте, двигателе, производителе и источнике.
- Три векторных схематических вида: снизу, спереди и сбоку. Они не являются конструкторскими чертежами.
- Локальная база карточек, поиск по всем полям, избранное, сортировка по характеристикам, фильтры по типу.
- Добавление, редактирование, удаление записей и фотографии из системного файлового интерфейса.
- Импорт и экспорт пользовательского каталога в JSON через Android Storage Access Framework.
- AMOLED / тёмная / светлая темы, пять цветовых акцентов, выключаемые анимации, тематические векторные иконки.
- Проверка обновлений при открытии (не чаще одного раза за сутки) и вручную из настроек.

Начальная карточка **МАРА-2М** создана по изображению, переданному пользователем. Её характеристики не были независимо проверены и помечены соответствующим источником. Добавленные пользователем записи хранятся локально.

## Android и сборка

- Application ID: dev.infend.bplainfo
- Актуальные versionName/versionCode определяются `app/build.gradle`; опубликованную версию проверяйте по GitHub Releases и подписанному APK.
- minSdk 26 / targetSdk 35
- Java 17, Android Gradle Plugin 9.3.1, Gradle 9.6.1
- Папка исходников: app/src/main/java/dev/infend/bplainfo/
- Workflow: .github/workflows/ota-release.yml

Запуск сборки в GitHub: вкладка **Actions** → **BPLA INFO Android OTA** → **Run workflow**. Workflow также реагирует на изменения приложения в main.

## OTA без браузера

Проверка: https://github.com/INFEND/BPLA-INFO/releases/latest/download/update.json

APK: https://github.com/INFEND/BPLA-INFO/releases/latest/download/BPLA-INFO.apk

Релиз публикуется только после компиляции, проверки данных и подписания постоянным ключом.

Приложение проверяет пакет и номер версии, скачивает APK в собственный кэш по HTTPS, сравнивает размер, SHA-256 и сертификат цифровой подписи с установленным приложением, затем открывает системный установщик Android. Браузер для обновления не используется. Для первой установки из приложения Android может запросить отдельное разрешение «Установка неизвестных приложений». Кнопка «Открыть» системного установщика работает через экспортированную MainActivity с категорией LAUNCHER.

## Постоянный ключ

GitHub Actions читает **BPLA_INFO_SIGNING_BUNDLE**. Для совместимости с инфраструктурой INFEND поддерживается также секрет из списка INFEND_SIGNING_BUNDLE, ANDROID_SIGNING_BUNDLE, QR_LINK_SIGNING_BUNDLE (первый найденный непустой). Нельзя менять сертификат после первого установленного релиза.

Формат секрета: Base64-представление ZIP с файлом signing.json и единственным файлом *.p12 в корне архива. Пример структуры signing.json:

    {
      "alias": "release",
      "keystore_password": "<PASSWORD>",
      "key_password": "<PASSWORD>",
      "certificate_sha256": "<64 HEX SYMBOLS>"
    }

Пароли и ключи нельзя коммитить. Если секрета нет или он не проходит проверку, рабочий процесс завершится ошибкой, а неподписанный APK **не будет** опубликован. Работоспособность релиза требует успешного завершения Actions, что не равнозначно наличию исходников в main.

## Формат экспорта

JSON объект с schema=1 и массивом items. При импорте записи с совпадающим id обновляются, новые id добавляются. Фото с локальным content URI могут быть недоступны на другом устройстве: переносите изображения отдельно.

Проект не подключается к БПЛА, не получает координаты и не осуществляет управление полётами.

## Фотографии: только локальные ресурсы APK

По требованию владельца 03.11.2026 удалены все прежние записи Wikimedia и сетевой загрузчик изображений. Приложение **никогда не скачивает фотографии моделей по ссылкам**: фотографии отображаются только из `app/src/main/assets/photos/` и из файлов, добровольно выбранных пользователем в системном проводнике.

- Манифест: `app/src/main/assets/bundled_photos.json` (schema 2). Для каждой модели перечисляются пути внутри APK, SHA-256 байтов, автор, лицензия и текстовое указание происхождения. URL не поддерживаются.
- Разрешённые пути: `photos/<имя>.webp`, `photos/<имя>.png` или `photos/<имя>.jpg`. Для каждой модели максимум пять уникальных ракурсов.
- В APK включать исключительно реальные фотографии с подтверждённым правом распространения. Исходные изображения сохраняются без обрезки, удаления фона, улучшения или перекодирования; SHA-256 встроенных байтов должен совпадать с исходным SHA-256. Пустые или неподтверждённые карточки должны оставаться пустыми с понятной подсказкой, никакой нейросетевой подмены фотографий.
- Устаревший кэш загрузок `uav-photos` удаляется после обновления. Пользовательские фото, добавленные через системный выбор файлов, сохраняются.
- Изображения загружаются из AssetManager без интернета. Сетевое разрешение оставлено только для OTA приложения.

Обновление бинарных изображений распространяется через штатную подписанную OTA приложения. Старые сетевые фотоисточники больше не используются.
