# БПЛА ИНФО

Нативный русскоязычный Android-каталог БПЛА. Первый образец МАРА-2М заполнен по присланному изображению и не прошёл независимую проверку. Иллюстрации схематические.

APK: BPLA-INFO.apk. OTA manifest: https://github.com/INFEND/BPLA-INFO/releases/latest/download/update.json

Сборка: Java 17, Gradle 9.6.1, AGP 9.3.1. Для подписанного релиза нужен постоянный секрет BPLA_INFO_SIGNING_BUNDLE (Base64 ZIP: signing.json и PKCS12). Не храните ключ в репозитории.
