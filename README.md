# БПЛА ИНФО

Русскоязычный Android-каталог беспилотных летательных аппаратов. Исходные данные первой карточки «МАРА-2М» взяты с предоставленной пользователем иллюстрации; сторонние карточки не подменяются выдуманными характеристиками.

Исходники приложения, OTA-процесс и правила релиза включаются в этот репозиторий.
