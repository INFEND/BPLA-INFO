# Фотоматериалы для продолжения разработки

Проверено 03.11.2026. Здесь лежат **исходники для обработки**, а не готовая
фотогалерея приложения. Ни один новый снимок из этой папки пока не включён в APK.

В `source_index.json` сохранены авторы, страницы DVIDS, отметки Public Domain,
контрольные суммы и причины, по которым фото ещё не готовы к публикации.
В `originals/` сохранены шесть неизменённых файлов из публичных версий DVIDS
шириной около 2000 пикселей и двадцать исходных WebP из фоторепортажа
АрміяInform. Это опубликованные версии, не полноразмерные оригиналы камеры.

| Модель | DVIDS | Состояние |
|---|---|---|
| PUMA AE RQ-20 | 8347955, 6381574 | Исходники двух уже встроенных фото. Попытки автоматической вырезки отклонены: ореолы и изменение деталей. |
| PUMA LE | 9457880, 9457884 | Два новых исходника. Проверить перекрытие человеком и аккуратно отделить фон. |
| VECTOR | 9499015, 9499028 | Два новых исходника. Проверить перекрытие человеком и травой. |

Не восстанавливать скрытые части генерацией и не выдавать восстановленные детали
за фотографию. Само наличие альфа-канала не доказывает корректную вырезку.
Если исходный кадр не позволяет сохранить полный аппарат, искать другой кадр.

Состояние приложения осталось прежним: 2 фото одной модели из 87,
оба со статусом `needs_background_review`. В манифест добавлены проверяемые SHA-256
их сохранённых исходников. Проверка на настоящем Android здесь не выполнялась.

## Пакетный импорт

Использовать единый импортёр `scripts/batch_import_photos.py`, добавленный
в основной теме. Не создавать второй конкурирующий механизм.
Полная инструкция: `docs/batch_photo_import.md`.

```sh
python3 scripts/batch_import_photos.py --staging /path/to/bundle
python3 scripts/batch_import_photos.py --staging /path/to/bundle --apply
python3 -m unittest discover -s tests -v
```

Первая команда проверяет пакет без записи. Вторая записывает его только после
фактической проверки прав, модели и качества вырезки. Пример `batch.json` ниже
намеренно не одобрен; заменить значения и поставить подтверждение можно только
после настоящего сравнения изображений:

```json
{
  "photos": [{
    "model_id": "lostarmour-pdf-2024-042",
    "model_name": "PUMA LE",
    "file_name": "puma_le_rear.png",
    "original": "originals/source.jpg",
    "prepared": "approved/puma_le_rear.png",
    "original_sha256": "SHA-256 точных байтов исходника",
    "prepared_sha256": "SHA-256 точных байтов готового файла",
    "author": "Автор из официального источника",
    "license": "Public domain (U.S. Government)",
    "source": "DVIDS ID, дата, модель; без сетевого адреса",
    "rights_evidence": "Конкретное подтверждение redistribution и modification; не предположение",
    "processing_status": "background_removed_verified",
    "visual_review_approved": false,
    "visual_review_notes": "Что действительно проверено при сравнении с исходником"
  }]
}
```

Все входные пути относительны папке `batch.json`. Готовые изображения попадут
в APK, а неизменённые исходники — в `photo_originals/<model_id>/` вне APK.

Дополнительно исправлены проверки: один исходник нельзя выдать за несколько
ракурсов, вырезка не должна касаться границы кадра, указанный хеш готового
файла обязан совпадать с его байтами. Существующие неиндексированные файлы
не перезаписываются. При ошибке записи или замены файлов пакет откатывается;
временные и частично подготовленные файлы удаляются.

Операция не защищает от отключения питания посреди записи. После неё нужны
обычный просмотр diff и CI. Импорт не является сборкой, выпуском OTA или
проверкой Android BitmapFactory. Версию повышать после появления полезного
готового контента и успешной CI.

## Дополнительные исходники и требование трёх ракурсов

`armyinform_review.json` содержит двадцать сохранённых снимков с проверенным
авторством Антона Шевельова / Министерства обороны Украины: семь «Домахи»,
семь А1-СМ «Фурии» и шесть Cetus. Источник — [авторский фоторепортаж
АрміяInform от 10.11.2025](https://armyinform.com.ua/2025/11/10/pyatirka-krylatyh-z-yastrubiv-gostrozori-drony-rozvidnyky-prochisuyut-vorozhyj-tyl/).
Условия: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), согласно
[политике издателя](https://armyinform.com.ua/site-usage-policy/).
Исходные файлы не изменены. Перед публикацией обработанных версий в приложении
нужны видимые авторство, ссылка на источник и лицензию, а также описание изменений.
Ссылка на авторство не должна становиться загрузчиком сетевых фотографий.

Это двадцать исследованных исходников, **не двадцать готовых ракурсов**.
В реестре для каждого отмечены обрезанные края, перекрытия руками и растительностью,
близкие повторяющиеся ракурсы. Наиболее чистые исходники: «Домаха» после запуска
(`05-2-scaled.webp`) и «Фурия» сверху (`12-1-scaled.webp`). Скрытые детали
не дорисовывать. Генеративная обработка «Фурии» отклонена: изменила надпись
и мелкие детали, поэтому её результат не включён ни в исходники, ни в APK.

Обычный SHARK из этого репортажа исключён: он не подтверждает MINI SHARK.
Songbird отсутствует в каталоге. В другом репортаже о «Лелеке-100» просмотрены
12 скачанных фотографий; точная версия BASIC/EFT/LR не установлена, привязки нет.

`coverage_min3.json` — снимок покрытия всех 87 моделей на 03.11.2026.
Цель: не менее 261 проверенной фотографии с удалённым фоном.
Фактически встроено 2 фотографии, проверенных вырезок 0, полностью готовых
моделей 0. Архив содержит 26 исходников-кандидатов для 6 моделей.
При следующем импорте пересчитать снимок по фактическим файлам и манифесту;
не считать наличие исходника выполнением требования пользователя.
