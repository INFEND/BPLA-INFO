Точное текущее количество файлов определяют `bundled_photos.json` и пересчитанный отчёт, а опубликованную версию — GitHub Release. Сохранение пакета в репозитории само по себе не подтверждает публикацию APK.

Файлы в `app/src/main/assets/photos/` физически включаются в APK. Их неизменённые копии в `photo_originals/<model_id>/` служат архивом вне APK. JSON доказательств содержит исходную публикацию, точный адрес скачанного изображения, автора, лицензию, размеры, SHA-256 и результаты визуальной проверки.

«Оригинал» здесь означает неизменённый опубликованный файл издателя, а не RAW или максимальное разрешение камеры. Изображения не перекодировались и не очищались от фона. Авторство и ссылка на лицензию доступны в полноэкранном просмотре приложения.

## Порядок импорта

Подробный формат: `docs/batch_photo_import.md`. Используется один импортёр; сам он не устанавливает подлинность модели или права на фотографию.

```sh
python3 scripts/batch_import_photos.py --staging /path/to/bundle
python3 scripts/batch_import_photos.py --staging /path/to/bundle --apply
python3 scripts/photo_progress.py --json > research/photos/coverage_min3.json
python3 -m unittest discover -s tests -v
```

Новый пакет использует `processing_status: verified_unmodified_original`, одинаковый файл для `original` и `prepared`, реальные контрольные суммы, подтверждения визуальной проверки, модели и отдельного полезного ракурса. Не выставлять подтверждения по одному заголовку страницы.

Ссылки для атрибуции записываются отдельно в `app/src/main/assets/photo_credits.json`; сетевого загрузчика фотографий нет. Дубли карточек могут ссылаться на одну галерею только через явно проверенный `aliases` в манифесте. Это не создаёт дополнительные физические снимки и не объединяет разные версии аппарата.

## Исторические материалы

`source_index.json`, `armyinform_review.json`, старые предложения масок и файлы в `originals/` отражают прежние этапы исследования. Отказ от неудачной вырезки не является отказом от её настоящего исходного фото при новой политике. Публиковать изменённый результат вместо исходника нельзя. Wikimedia/Wikipedia и синтетические фотографии не использовать.

Проверки APK удостоверяют наличие файлов, их хеши, поддерживаемый формат и декодирование; они не заменяют визуальную идентификацию и тест на физическом устройстве. Вся задача по 3–5 фото для каждой карточки ещё не завершена.
